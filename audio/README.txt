======================================================
  HOW TO ADD YOUR SONGS TO THE JUKEBOX
======================================================

Place your MP3 files in THIS folder (new4/audio/) with these EXACT names:

  song1.mp3  →  Kavithe Kavithe    (Yuva - Sanjith Hegde)
  song2.mp3  →  Happy              (AllOk)
  song3.mp3  →  Friendship         (Lucky Man - Puneeth Rajkumar)
  song4.mp3  →  Lokada Kalaji      (Raghu Dixit Project)
  song5.mp3  →  Nee Sigoovaregu    (Bhajarangi 2 - Sid Sriram)

STEPS:
1. Download/find the MP3 file for each song
2. Rename it to the matching filename above (e.g., song1.mp3)
3. Copy it into this audio/ folder
4. Refresh the website — the song will play directly!

TIPS:
- You can also use .ogg or .wav files — just update the filenames in index.html
- Make sure the server is running (http://localhost:3000)
- Songs work 100% locally without any internet connection
